# Shopping-discount-calculator


This is a shopping discount calculator that I created using Python!

The program asks for:

1. The original bill amount
2. The discount percentage
3. The number of people splitting the bill

Based on those pieces of information, the program calculates the discount amount, the final amount after the discount, and how much each person needs to pay.

If the user enters invalid information, like a negative number or something that can't be converted into a number, the program gives an error message and asks them to enter the information again.

Features include:

1. User input and interaction
2. Calculating discounts
3. Splitting the final bill between multiple people
4. Using try and except to handle errors
5. Using else and finally
6. Converting inputs using float() and int()
7. Rounding the amount each person pays
8. Handling invalid inputs

What I learnt:

1. How to use try and except to handle errors
2. How to use else and finally with error handling
3. How to validate user input
4. How to calculate percentages using Python
5. How to split an amount between multiple people
6. How to use round() to make the final amount much easier to read
7. How to use multiple values from one user input by using .split(",")

About this project:

This is a shopping discount calculator I made in Python that calculates the final price after a discount and splits the cost between multiple people. When I was building this program, I learned more about error handling and making sure the user enters valid information. This project helped me get more comfortable with `try`, `except`, `else`, and `finally` and how they can be used to make a program handle errors.
